# Видео в блоках «О компании» и контактов

В `public/motion/` находятся оптимизированные версии трёх предоставленных роликов:

- `about-team.mp4` — первый файл пользователя, команда за ноутбуком.
- `about-triangle.mp4` — второй файл, треугольник и орбиты.
- `summit.mp4` — третий файл, гора с людьми и световой тропой.

MP4: H.264, yuv420p, 24 кадра/с, faststart; звуковые дорожки удалены. Ролики повторяются с исходной длительностью. Монтажные стыки исходников сохранены.

`src/components/AmbientVideo.tsx` загружает видео при появлении в видимой области. Воспроизведение без звука, inline на мобильных устройствах. Вне экрана и в скрытой вкладке видео приостанавливается. Системное сокращение движения и общая кнопка паузы показывают статичный постер. Если браузер блокирует автозапуск или файл недоступен, постер остаётся видимым.

Для замены положите новый MP4 под тем же именем и обновите соответствующий `*-poster.webp`. Для треугольника также замените `triangle-mask.png`: это мягкая альфа-маска границ исходного кадра. Небольшие демонстрационные экраны и рукописные слова остаются отдельными элементами сайта. В финале удалена прежняя SVG-анимация тропы, поскольку она уже присутствует в ролике.

Запуск и Vercel — по основному README. Локальный сервер поддерживает HTTP Range для видео.
